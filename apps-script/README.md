# Google Apps Script Web App API

Mã nguồn `apps-script/Code.gs` dùng để triển khai Web App API trên Google Sheets cho ứng dụng Heo & Mèo Finance.

## Hướng dẫn cài đặt:
1. Mở Google Sheet -> **Tiện ích mở rộng (Extensions)** -> **Apps Script**.
2. Dán toàn bộ nội dung từ tệp `apps-script/Code.gs` vào.
3. Bấm **Triển khai (Deploy)** -> **Tùy chọn triển khai mới (New deployment)**.
4. Chọn loại **Ứng dụng web (Web app)**:
   - Thực thi dưới dạng: **Tôi (Me)**
   - Ai có quyền truy cập: **Bất kỳ ai (Anyone)**
5. Sao chép URL ứng dụng web và dán vào tab "Đồng bộ Sheets" trên ứng dụng.
